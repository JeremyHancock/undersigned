undersigned

A broker (this page) and a notes service run as two separate servers that only talk over HTTP. You sign approvals with a real passkey; the service checks each request for itself.

This is a demo: your session and its notes are held in memory and forgotten after 30 idle minutes. The passkey it creates is only for this page; you can delete it from your password manager afterwards. Source and design notes.

1Create a passkey

Registers a passkey with the broker. The broker then links your account at the service, which pins the passkey's public key.

2Approve a standing grant

One approval for an envelope of actions. Your passkey signs the digest of the grant document itself.

3Let the agent act

Each button makes the agent send one request to the service.

The grant allows 3 writes a day. Deleting everything is critical risk, so it can never be covered by a standing grant.

4Revoke

Ends every grant you have made, including any single-use approval you signed but the agent has not used yet, and pushes a signed revocation event for each to the service.
